# RDK Retro UI consumer mirror

This is a consumer distribution mirror for RDK Retro UI 0.1.0-alpha.4. Disclosure, Range, and Breadcrumbs are public components. Development happens in a separate canonical repository. Read [RDK_AGENT_GUIDE.md](RDK_AGENT_GUIDE.md) before generating UI. The [Showcase](docs/showcase/) opens the active theme Native Showcase. Choose Console 94, Terminal OS, or Czarek OS with data-rdk-theme on the root. Check docs/support/ for each shared component status: supported, fallback, or unsupported. Terminal Window is a Terminal OS-specific primitive; Czarek OS uses a slate-first visual system and theme-scoped status/icon recipes; prompts and logs are ordinary content. Native Showcase is each theme's canonical visual presentation; labelled candidates and recipes do not change shared API status. [Compatibility Showcase](docs/showcase/shared/) compares shared semantic markup across themes for regression. Component classes stay the same where supported. Do not infer undocumented `rdk-*` APIs. Tailwind or application CSS controls geometry; RDK controls visual identity. Use native semantic HTML and application JavaScript for behavior.
