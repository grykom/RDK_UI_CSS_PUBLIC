# RDK Retro UI consumer mirror

This is a consumer distribution mirror for RDK Retro UI 0.1.0-alpha.3. Disclosure, Range, and Breadcrumbs are public components. Development happens in a separate canonical repository. Read [RDK_AGENT_GUIDE.md](RDK_AGENT_GUIDE.md) before generating UI. The [Showcase](docs/showcase/) opens the active theme Native Showcase. Choose Console 94 or Terminal OS with data-rdk-theme on the root. Check docs/support/ for each shared component status: supported, fallback, or unsupported. Terminal Window is a Terminal OS-specific primitive; prompts and logs are ordinary content. Native Showcase is the theme composition; [Compatibility Showcase](docs/showcase/shared/) tests shared markup. Component classes stay the same where supported. Do not infer undocumented `rdk-*` APIs. Tailwind or application CSS controls geometry; RDK controls visual identity. Use native semantic HTML and application JavaScript for behavior.
