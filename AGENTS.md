# RDK Retro UI consumer mirror

This is a consumer distribution mirror. Development happens in a separate canonical repository. Read [RDK_AGENT_GUIDE.md](RDK_AGENT_GUIDE.md) before generating UI. Do not infer undocumented `rdk-*` APIs. Tailwind or application CSS controls geometry; RDK controls visual identity. Use native semantic HTML and application JavaScript for behavior.
