# RDK Retro UI consumer mirror

This is a consumer distribution mirror for RDK Retro UI 0.1.0-alpha.4. Development happens in the canonical repository. Read RDK_AGENT_GUIDE.md before generating UI. Shared components include Disclosure, Range, and Breadcrumbs. Check docs/components/ and docs/data/theme-capabilities.json for supported, fallback, and unsupported status per selected theme. Open Demo from docs/ for the selected theme native showcase. Theme-specific primitives are listed in the capability manifest. Tailwind or application CSS controls geometry; RDK controls visual identity. Use semantic HTML and application JavaScript for behavior.
