Komponenty / Card

Card

Karta treści lub opcjonalnie interaktywny wybór.

← Wszystkie komponenty
01 / PODGLĄD

Na żywo

02 / PODSTAWY

Kod do użycia

Przykład poniżej jest tym samym znacznikiem, którego używa podgląd.

HTML
<button type="button" class="rdk-card rdk-card-interactive grid max-w-sm gap-2 p-5 text-left" aria-pressed="false" data-card-toggle>
<span class="rdk-label">Profil</span>
<strong>Moduł B2</strong>
<span class="text-rdk-text-muted text-sm">Wybierz profil serwisowy.</span>
</button>
03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Statyczny rdk-card i interaktywny rdk-card-interactive.

Stany

Hover, active, aria-pressed, aria-current i disabled dla wersji interaktywnej.

04 / ACCESSIBILITY

Semantyka i klawiatura

Gdy karta działa jak przycisk, użyj button i aktualizuj stan aria-pressed. Dla nawigacji użyj linku.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.

06 / PUBLIC API

Klasy CSS

.rdk-card.rdk-card-interactive
07 / ZACHOWANIE

Odpowiedzialność aplikacji

Aplikacja aktualizuje aria-pressed; skrypt dokumentacji obsługuje pokazany przykład.
