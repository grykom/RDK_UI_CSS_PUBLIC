Card

01 / PREVIEW

Live preview

02 / BASICS

Reusable markup

The markup below is the same markup used by the live preview.

HTML
<button type="button" class="rdk-card rdk-card-interactive grid max-w-sm gap-2 p-5 text-left" aria-pressed="false" data-card-toggle>
<span class="rdk-label">Profile</span>
<strong>Module B2</strong>
<span class="text-rdk-text-muted text-sm">Choose a service profile.</span>
</button>
03 / WARIANTY I STANY

Available options

Warianty

Static card and interactive card.

Stany

Hover, active, aria-pressed, aria-current, and disabled for the interactive form.

04 / ACCESSIBILITY

Semantics and keyboard

Use a button and update aria-pressed when the card is a choice. Use a link for navigation.
05 / TAILWIND + RDK

Composition

RDK classes provide appearance. Tailwind classes in this example control size, padding, grid, spacing, and position. Keep layout utilities in the application.

06 / PUBLIC API

CSS classes

.rdk-card.rdk-card-interactive
07 / BEHAVIOR

Application responsibility

The application updates aria-pressed; the documentation script handles the demo.
