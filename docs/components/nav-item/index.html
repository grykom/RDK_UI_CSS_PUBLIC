03 / WARIANTY I STANY

Available options

Warianty

Use a link with href or a button. Icon and meta are optional; data-accent selects one of eight accents.

Stany

Hover, active, focus-visible, aria-current for links, aria-pressed for local selection, and disabled for buttons.

04 / ACCESSIBILITY

Semantics and keyboard

Links preserve navigation and aria-current. Use a button and aria-pressed only for a local toggle. Decorative icons can be aria-hidden. A border and recessed state reinforce the selected item.
05 / TAILWIND + RDK

Composition

RDK classes provide appearance. Tailwind classes in this example control size, padding, grid, spacing, and position. Keep layout utilities in the application.

06 / PUBLIC API

CSS classes

.rdk-nav-item.rdk-nav-item-icon.rdk-nav-item-label.rdk-nav-item-meta
07 / BEHAVIOR

Application responsibility

Update aria-pressed when the selection changes. The demo script shows this behavior. Provide an accessible name for truncated labels.
