03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Domyślny blue lub data-accent z ośmiu kolorów palety.

Stany

Segmenty z data-active i bez niego.

04 / ACCESSIBILITY

Semantyka i klawiatura

Dla postępu ustaw role="progressbar" i aria-value*. Liczba aktywnych segmentów musi zgadzać się z tekstem.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.
