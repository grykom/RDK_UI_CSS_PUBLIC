02 / PODSTAWY

Kod do użycia

Przykład poniżej jest tym samym znacznikiem, którego używa podgląd.

HTML
<div class="overflow-x-auto">
<table class="rdk-table min-w-[38rem] w-full">
<caption>Stan modułów.</caption>
<thead>
<tr>
<th scope="col">Moduł</th>
<th scope="col">Status</th>
<th scope="col" data-align="numeric">Obciążenie</th>
</tr>
</thead>
<tbody>
<tr>
<th scope="row">A4</th>
<td>
<span class="rdk-badge rdk-badge-success px-2 py-1 text-xs">Gotowy</span>
</td>
<td data-align="numeric">68%</td>
</tr>
<tr data-state="warning">
<th scope="row">B2</th>
<td>
<span class="rdk-badge rdk-badge-danger px-2 py-1 text-xs">Kontrola</span>
</td>
<td data-align="numeric">91%</td>
</tr>
</tbody>
</table>
</div>
03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Wiersz z data-state="warning", komórka z data-align="numeric".

Stany

Hover wiersza. Pusty stan powinien być osobnym opisem w aplikacji.

04 / ACCESSIBILITY

Semantyka i klawiatura

Zachowaj caption oraz scope na nagłówkach. Poziomy scroll zapewnia wrapper Tailwind.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.
