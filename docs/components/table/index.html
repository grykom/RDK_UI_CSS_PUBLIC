4 / BASICS

Reusable markup

The markup below is the same markup used by the live preview.

HTML
<div class="overflow-x-auto">
<table class="rdk-table min-w-[38rem] w-full">
<caption>Module status.</caption>
<thead>
<tr>
<th scope="col">Module</th>
<th scope="col">Status</th>
<th scope="col" data-align="numeric">Load</th>
</tr>
</thead>
<tbody>
<tr>
<th scope="row">A4</th>
<td>
<span class="rdk-badge rdk-badge-success px-2 py-1 text-xs">Ready</span>
</td>
<td data-align="numeric">68%</td>
</tr>
<tr data-state="warning">
<th scope="row">B2</th>
<td>
<span class="rdk-badge rdk-badge-warning px-2 py-1 text-xs">Needs inspection</span>
</td>
<td data-align="numeric">91%</td>
</tr>
</tbody>
</table>
</div>
