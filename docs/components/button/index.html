5 / STATES

States

Hover, active, pressed, disabled, and focus-visible. Solid and outline support eight accents.

6 / ACCESSIBILITY

Semantics and keyboard

Use a real button with a text label. Update aria-pressed for a toggle and set the correct form type. Do not rely on color alone for destructive actions.
7 / TAILWIND + RDK

Composition

RDK classes provide appearance. Tailwind classes in this example control size, padding, grid, spacing, and position. Keep layout utilities in the application.

8 / PUBLIC API

9 / STATES

Disabled, pressed, and focus

Use Tab to see the shared focus-visible state. Use the pressed state only for toggle buttons.

DH / DARK HORSE PATTERN

Busy Action

For long-running work, keep the visible action label stable, set aria-busy="true" while active, and disable repeat activation when needed. Show a stage message separately; optional indeterminate Progress is an existing component. Application code returns the action to idle or reports success/error. This is a Pattern, not a Button variant. See Busy Action and operational Patterns.
