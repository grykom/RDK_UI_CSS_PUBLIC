Na żywo

02 / PODSTAWY

Kod do użycia

Przykład poniżej jest tym samym znacznikiem, którego używa podgląd.

HTML
<div class="flex flex-wrap items-center gap-3">
<button type="button" class="rdk-btn rdk-btn-primary h-10 px-4 text-sm">Zapisz</button>
<button type="button" class="rdk-btn rdk-btn-solid h-10 px-4 text-sm" data-accent="blue" >Edytuj</button>
<button type="button" class="rdk-btn rdk-btn-solid h-10 px-4 text-sm" data-accent="pink" >Wyróżnij</button>
<button type="button" class="rdk-btn rdk-btn-solid h-10 px-4 text-sm" data-accent="orange" >Eksportuj</button>
<button type="button" class="rdk-btn rdk-btn-outline h-10 px-4 text-sm" data-accent="red" >Na sprzedaż</button>
<button type="button" class="rdk-btn rdk-btn-solid h-10 px-4 text-sm" data-accent="blue" disabled>Niedostępne</button>
</div>
03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Normalne: neutralny, primary, success, danger, special. Mocniejsze: solid i outline z data-accent.

Stany

Hover, active, aria-pressed="true", disabled i focus-visible. Solid i outline obsługują osiem akcentów.

04 / ACCESSIBILITY

Semantyka i klawiatura

Używaj prawdziwego button z nazwą tekstową. Przycisk przełączający aktualizuje aria-pressed; akcję formularza oznacz właściwym type. Kolor nie zastępuje tekstu, zwłaszcza przy akcji destrukcyjnej.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.

06 / PUBLIC API

Klasy CSS

.rdk-btn.rdk-btn-primary.rdk-btn-success.rdk-btn-danger.rdk-btn-special.rdk-btn-solid.rdk-btn-outline
07 / PRZYCISKI

Normalne hardware buttons

08 / SOLID ACTIONS

Mocne działania

Solid używa koloru z data-accent i przypisanego mu kontrastowego koloru tekstu. Wybieraj go dla głównej akcji ekranu.

HTML
<button type="button" class="rdk-btn rdk-btn-solid h-10 px-4 text-sm" data-accent="blue" >Edytuj</button>
09 / OUTLINE ACTIONS

Lżejsze wyróżnienie

Outline zachowuje jasną plastikową powierzchnię i akcentuje dolną oraz prawą krawędź.

11 / STATES

Disabled, pressed i focus

Nawiguj Tab, aby zobaczyć wspólny focus-visible. Stan pressed stosuj tylko dla przełącznika.

12 / TAILWIND

Rozmiar po stronie układu

Wysokość, padding i rozmiar pisma dobieraj klasami Tailwind: h-10 px-4 text-sm. Klasy rdk-btn-solid i rdk-btn-outline nadają wyłącznie wygląd.
