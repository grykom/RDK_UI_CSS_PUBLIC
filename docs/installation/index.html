Installation

Add the CSS, choose a theme, and use semantic HTML.

What RDK provides

RDK supplies colors, surfaces, type and control appearance. Your application or Tailwind controls layout, size and positioning. Interaction stays in your application.

Import the CSS

Clone or download the consumer repository. RDK is not on the public npm registry or a CDN. Import the source into a Tailwind v4 build, or copy the compiled CSS and sibling fonts into a plain CSS app.

Show Tailwind import
@import "tailwindcss";
@import "./path/to/RDK/src/index.css";
Show built CSS import
<link rel="stylesheet" href="./rdk-retro-ui.css">

Activate the selected theme

Use Console 94 on the application root. The code follows the theme selector.

<html data-rdk-theme="console-94">

First component

Show HTML
<button type="button" class="rdk-btn rdk-btn-primary">Save</button>

Working with a coding agent

Give your agent RDK_AGENT_GUIDE.md from the consumer repository or node_modules/@rdk/retro-ui/RDK_AGENT_GUIDE.md from a local package. Ask it to read the guide and the selected theme capability data before composing UI. Keep application layout and behavior in your code.

Show agent prompt
Read RDK_AGENT_GUIDE.md, use the selected theme from docs/data/themes.json, respect docs/data/theme-capabilities.json, and build semantic HTML with RDK appearance classes. The app owns layout and JavaScript.
