Installation

Add the CSS, choose a theme, and use semantic HTML.

What RDK provides

RDK supplies colors, surfaces, type and control appearance. Your application or Tailwind controls layout, size and positioning. Interaction stays in your application.

Import the CSS

Clone or download the consumer repository. RDK is not on the public npm registry or a CDN. Import source into a supported Tailwind v4 build, or copy prebuilt CSS and sibling fonts into an app with or without its own Tailwind pipeline.

Show Tailwind import
@import "tailwindcss";
@import "./path/to/RDK/src/index.css";
Show combined CSS import
<link rel="stylesheet" href="./rdk-retro-ui.min.css">

Combined bundle

The combined rdk-retro-ui.min.css includes Czarek OS, Terminal OS and Dark Horse. Use it for theme selection or runtime switching. Console 94 stays outside the combined file.

Show combined import
<html data-rdk-theme="dark-horse">
  <link rel="stylesheet" href="./rdk-retro-ui.min.css">
</html>

Single-theme bundles

For an application committed to one active theme, choose its standalone CSS below. Each file includes shared RDK styling, so load it instead of the combined CSS. Changing to another theme requires the combined bundle or another theme bundle. Keep the sibling fonts/ directory beside the CSS.

Show Czarek OS standalone import
<html data-rdk-theme="czarek-os">
  <link rel="stylesheet" href="./rdk-retro-ui.czarek-os.min.css">
</html>
Show Terminal OS standalone import
<html data-rdk-theme="terminal-os">
  <link rel="stylesheet" href="./rdk-retro-ui.terminal-os.min.css">
</html>
Show Dark Horse standalone import
<html data-rdk-theme="dark-horse">
  <link rel="stylesheet" href="./rdk-retro-ui.dark-horse.min.css">
</html>

For Tailwind 3.4 with default Preflight, use the matching rdk-retro-ui.THEME.compat.min.css file after your compiled Tailwind CSS.

Archived theme

Console 94 is archived and excluded from the combined CSS. To keep using it, load its complete rdk-retro-ui.console-94.min.css standalone file and sibling fonts with data-rdk-theme="console-94". Open the Console 94 archive.

Dark Horse is a public alpha theme for control, monitoring, dashboards, and focused utilities. Its standalone bundle is rdk-retro-ui.dark-horse.min.css; it supports 24 shared components and keeps Tooltip as fallback.

Open the Dark Horse Native Showcase

Prebuilt CSS with an existing Tailwind project

For Tailwind 3.4 with default Preflight, use the generated compatibility CSS after the application Tailwind CSS. Preflight is unlayered and overrides normal layered RDK rules even when the normal RDK file loads later. Keep the fonts/ directory beside the RDK CSS file; its font URLs are relative.

Show Tailwind 3 example
<html data-rdk-theme="console-94">
<head>
  <link rel="stylesheet" href="/assets/app-tailwind.css">
  <link rel="stylesheet" href="/rdk/rdk-retro-ui.compat.min.css">
</head>
<body>
  <button class="rdk-btn rdk-btn-solid" data-accent="green">Action</button>
</body>
</html>

Activate the selected theme

Use Czarek OS on the application root. The code follows the theme selector.

<html data-rdk-theme="czarek-os">

Customize a theme

Override documented RDK theme tokens after the CSS import. This preserves component semantics but may differ from the Native Showcase; check contrast in your application. Avoid copying internal .rdk-* selectors.

Show token override
:root[data-rdk-theme="terminal-os"] {
  --rdk-case: #050607;
  --rdk-font-ui: "JetBrains Mono", Consolas, monospace;
  --rdk-font-display: var(--rdk-font-ui);
  --rdk-font-mono: var(--rdk-font-ui);
}

Working with a coding agent

Give your agent RDK_AGENT_GUIDE.md from the consumer repository or node_modules/@rdk/retro-ui/RDK_AGENT_GUIDE.md from a local package. Ask it to read the guide and the selected theme capability data before composing UI. Keep application layout and behavior in your code.

Show agent prompt
Read RDK_AGENT_GUIDE.md, use the selected theme from docs/data/themes.json, respect docs/data/theme-capabilities.json, and build semantic HTML with RDK appearance classes. The app owns layout and JavaScript.
