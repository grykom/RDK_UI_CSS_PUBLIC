Start / Integration

Installation

RDK Retro UI is available through the public consumer repository, a local .tgz package, repository source, or built CSS. It is not published to the npm registry.

01 / RECOMMENDED

Tailwind v4 + local source

In a Tailwind application, import Tailwind first, then one public RDK stylesheet. Adjust the path for your repository or local workspace.

app.css
@import "tailwindcss";
@import "./path/to/rdk-retro-ui/src/index.css";

The local package name is @rdk/retro-ui, but the project has private: true. Registry installation is not available.

02 / BUILT CSS

Built stylesheet

The build creates dist/rdk-retro-ui.css, a minified version, and dist/fonts/. Copy CSS with its sibling fonts directory. RDK does not include Tailwind layout utilities; add compiled Tailwind CSS or your own layout rules.

HTML / your static server
<link rel="stylesheet" href="/assets/tailwind.css">
<link rel="stylesheet" href="/assets/rdk-retro-ui.css">

The /assets/ paths are examples for your application, not a hosted RDK endpoint.

03 / REPOSITORY

Run the documentation

Terminal
npm install
npm run dev
npm run build

Vite serves the documentation and builds dist/docs/ for production.

04 / WINDOWS / CLI

Build without Node

PowerShell
.\scripts\build-local.ps1
python -m http.server 4173 -d dist/docs

The script uses the local Tailwind CLI and checked-in HTML pages. After changing generated content, run the Node documentation generator before using this path.

05 / PRIVATE PACKAGE

Install a local tarball

The owner can create a .tgz package with npm run release:prepare and share it directly. Install the received file without using the npm registry.

Terminal
npm install ./rdk-retro-ui-0.1.0-alpha.3.tgz
app.css / Tailwind v4
@import "tailwindcss";
@source "./index.html";
@import "@rdk/retro-ui/source.css";

Built CSS is available as @rdk/retro-ui/dist.css or @rdk/retro-ui/dist.min.css. When copying CSS into an application, copy the sibling fonts/ directory too.

06 / THEME

Activate the selected theme

Active theme: Console 94. Warm equipment surfaces, IBM Plex typography, subtle bevels and LCD readouts.

HTML
<html data-rdk-theme="console-94">
<button class="rdk-btn rdk-btn-primary">Inspect</button>
</html>

Open Native Showcase / Theme details

Active theme: Terminal OS. Terminal-inspired interface on a blue-black, navy and graphite base. Green signals prompts, success and actions.

HTML
<html data-rdk-theme="terminal-os">
<button class="rdk-btn rdk-btn-primary">Inspect</button>
</html>
