Start / Integracja

Instalacja

RDK Retro UI jest dostępny przez publiczne repozytorium konsumenckie, lokalny pakiet .tgz, źródło repozytorium lub gotowy CSS. Pakiet nie jest opublikowany w rejestrze npm.

01 / ZALECANE

Tailwind v4 + lokalne źródło

W aplikacji z Tailwind zaimportuj najpierw Tailwind, potem jeden publiczny plik RDK. Ścieżkę dostosuj do położenia repozytorium lub lokalnego workspace.

app.css
@import "tailwindcss";
@import "./path/to/rdk-retro-ui/src/index.css";
index.html
<html data-rdk-theme="console-94">
  <button class="rdk-btn rdk-btn-primary h-10 px-4 text-sm">Zapisz</button>
</html>

Nazwa @rdk/retro-ui jest skonfigurowana lokalnie w package.json, ale projekt ma private: true. Import pakietowy z rejestru npm nie jest obecnie dostępny.

02 / GOTOWY CSS

Plik skompilowany

Build tworzy dist/rdk-retro-ui.css, wersję minifikowaną i katalog dist/fonts/. Skopiuj CSS razem z fontami, zachowując ich względną ścieżkę. Sam plik RDK nie zawiera narzędzi układu Tailwind; dołącz zbudowany CSS Tailwind lub własne reguły geometrii.

HTML / własny serwer statyczny
<link rel="stylesheet" href="/assets/tailwind.css">
<link rel="stylesheet" href="/assets/rdk-retro-ui.css">

Ścieżki /assets/ są przykładem lokalnej aplikacji, a nie adresem hostowanej usługi RDK.

03 / REPOZYTORIUM

Uruchamianie dokumentacji

Terminal
npm install
npm run dev
npm run build

Vite serwuje dokumentację i generuje produkcyjny katalog dist/docs/.

04 / WINDOWS / CLI

Build bez Node

PowerShell
.\scripts\build-local.ps1
python -m http.server 4173 -d dist/docs

Skrypt używa lokalnego Tailwind CLI i zapisanych w repozytorium stron HTML. Po zmianie treści generowanych stron uruchom generator dokumentacji w środowisku Node przed użyciem tej ścieżki.

05 / PACZKA PRYWATNA

Instalacja z lokalnego tarballa

Właściciel może przygotować paczkę poleceniem npm run release:prepare i udostępnić plik .tgz wybranym osobom. Instaluj z otrzymanego pliku, bez rejestru npm.

Terminal
npm install ./rdk-retro-ui-0.1.0-alpha.2.tgz
app.css / Tailwind v4
@import "tailwindcss";
@source "./index.html";
@import "@rdk/retro-ui/source.css";

Gotowy wariant jest dostępny jako @rdk/retro-ui/dist.css lub @rdk/retro-ui/dist.min.css. Jeśli kopiujesz CSS do katalogu aplikacji, skopiuj obok katalog fonts/.

06 / VANILLA

Minimalny projekt bez kompilacji Tailwind

Projekt examples/vanilla/ ładuje gotowy dist/rdk-retro-ui.css. Własny example.css ustala układ, a RDK nadaje wygląd komponentom.
