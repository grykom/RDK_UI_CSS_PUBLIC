Podstawy / Console 94

Kolory

Neutralny plastik stanowi większość interfejsu. Osiem akcentów nadaje tożsamość kategoriom, stanom i ważnym akcjom.

01 / SURFACES

Paleta powierzchni

--rdk-case
--rdk-surface
--rdk-surface-raised
--rdk-surface-recessed
--rdk-structure
02 / SEMANTICS

Kolor a znaczenie

Istniejące klasy rdk-btn-danger, rdk-notice-success i rdk-toast-danger zachowują semantyczną rolę. Akcenty kategoryczne przez data-accent nie zastępują opisów stanów.

04 / DISCIPLINE

Kolor używany celowo

Większość powierzchni aplikacji pozostaje neutralnym plastikiem Console 94. Akcenty identyfikują działania, stany, kategorie lub ważne kontrolki. Kolor wzmacnia tożsamość i stan, ale nigdy nie jest jedynym nośnikiem znaczenia.
05 / CONTRACT

Jeden atrybut

Navigation Item, Solid/Outline Button, Progress i Segments przyjmują data-accent="green|red|blue|pink|amber|orange|violet|cyan". Brak atrybutu oznacza akcent blue. Publiczne tokeny możesz dostosować w motywie.
