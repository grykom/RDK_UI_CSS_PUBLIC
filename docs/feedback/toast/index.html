02 / PODSTAWY

Kod do użycia

Przykład poniżej jest tym samym znacznikiem, którego używa podgląd.

HTML
<div>
<button type="button" class="rdk-btn h-10 px-4" data-toast-show data-toast-tone="success" data-toast-title="Zapisano" data-toast-message="Ustawienia są gotowe.">Pokaż sukces</button>
<div class="rdk-toast rdk-toast-success mt-4 flex items-start justify-between gap-3 p-4" aria-hidden="true">
<div>
<strong>Zapisano</strong>
<p class="mt-1 text-sm">Ustawienia są gotowe.</p>
</div>
<span class="rdk-label">PODGLĄD</span>
</div>
<div class="fixed bottom-4 right-4 z-50 w-[min(25rem,calc(100vw-2rem))]" data-toast-host aria-live="polite" aria-atomic="true">
</div>
</div>
03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Neutral, success, danger, info.

Stany

Pojawia się po akcji, znika po ręcznym zamknięciu; CSS nie ustala czasu.

04 / ACCESSIBILITY

Semantyka i klawiatura

Informacje i sukces: role="status"; pilny błąd: role="alert". Dismiss musi mieć dostępną nazwę.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.

06 / PUBLIC API

Klasy CSS

.rdk-toast.rdk-toast-neutral.rdk-toast-success.rdk-toast-danger.rdk-toast-info
07 / ZACHOWANIE

Odpowiedzialność aplikacji

Aplikacja tworzy i usuwa toast oraz ustala położenie. Skrypt dokumentacji pokazuje pojedynczy toast bez kolejki i timera.
