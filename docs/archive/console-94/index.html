Console 94

Console 94 is the original RDK visual theme. It is preserved as a standalone legacy theme but is no longer part of the default active distribution or ongoing feature development.

01 / LEGACY

Using Console 94

Set data-rdk-theme="console-94" on the application root and load dist/rdk-retro-ui.console-94.min.css with its sibling fonts/ directory. Its normal and compatibility variants remain available. The active combined stylesheet contains Czarek OS, Terminal OS and Dark Horse.

02 / REFERENCE

Original visual language

The original warm equipment surfaces, IBM Plex typography, bevels and LCD remain available in the archived Console 94 showcase. This theme receives critical compatibility fixes, not new features.
