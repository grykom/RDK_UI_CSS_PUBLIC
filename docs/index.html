02 / QUICK START

Trzy kroki do Console 94

Projekt nie jest opublikowany w rejestrze npm. Możesz użyć lokalnego tarballa albo importować źródło z repozytorium.

CSS / lokalnie zainstalowana paczka
@import "tailwindcss";
@source "./index.html";
@import "@rdk/retro-ui/source.css";
HTML / pierwszy przycisk
<html data-rdk-theme="console-94">
  <button class="rdk-btn rdk-btn-primary h-10 px-4 text-sm">Zapisz</button>
</html>
