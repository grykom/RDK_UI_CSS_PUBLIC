Tailwind v4

Samodzielna aplikacja Vite importuje źródłowy src/index.css po Tailwind. Klasy RDK nadają powierzchnie i kolory; Tailwind zapewnia układ i rozmiar.

01 / PLIKI

Projekt w repozytorium

examples/tailwind/index.html, src/app.css, src/app.js, vite.config.js i README. W katalogu przykładu uruchom npm install, npm run dev albo npm run build.
