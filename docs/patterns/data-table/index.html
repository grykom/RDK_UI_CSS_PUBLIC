02 / HTML

Skopiuj kompozycję

Kod jest identyczny z podglądem. Rozmiary, siatki i pozycje pochodzą z Tailwind.

HTML
<section class="grid gap-4" aria-label="Lista modułów">
<div class="overflow-x-auto">

<caption>Bieżący stan modułów.</caption>
<thead>

<th scope="col">Moduł</th>
<th scope="col">Lokalizacja</th>
<th scope="col">Status</th>
<th scope="col" data-align="numeric">Obciążenie</th>
</tr>
</thead>
<tbody>
<tr>
<th scope="row">A4</th>
<td>Hala główna</td>

<span class="rdk-badge rdk-badge-success px-2 py-1 text-xs">Gotowy</span>
</td>

03 / SEMANTYKA

Zasady użycia

Wrapper przewija szeroką tabelę bez przepełnienia strony. Caption i scope zachowują strukturę; ostrzeżenie i wyłączenie mają etykiety tekstowe. Pusty stan jest osobnym komunikatem.
