02 / HTML

Skopiuj kompozycję

Kod jest identyczny z podglądem. Rozmiary, siatki i pozycje pochodzą z Tailwind.

03 / SEMANTYKA

Zasady użycia

Menu i dialog wymagają zachowania aplikacji; dialog korzysta z showModal. Tooltip zawiera tylko dodatkową wskazówkę. Notice pozostaje w układzie, a toast jest ogłaszany po akcji.
