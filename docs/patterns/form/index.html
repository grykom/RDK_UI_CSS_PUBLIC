02 / HTML

Skopiuj kompozycję

Kod jest identyczny z podglądem. Rozmiary, siatki i pozycje pochodzą z Tailwind.

HTML
<form class="rdk-panel grid gap-5 p-5" data-demo-form>
<div class="grid gap-4 sm:grid-cols-2">
<label class="grid gap-2">
<span class="rdk-label">Nazwa stacji</span>
<input class="rdk-input h-10 w-full px-3" value="Stacja A4">
</label>
<label class="grid gap-2">
<span class="rdk-label">Tryb pracy</span>
<select class="rdk-select h-10 w-full px-3">
<option>Automatyczny</option>
<option>Ręczny</option>
</select>
</label>
</div>
<label class="grid gap-2">
<span class="rdk-label">Notatka operatora</span>
<textarea class="rdk-textarea min-h-24 w-full p-3">Odczyt stabilny.</textarea>
</label>
<fieldset class="grid gap-2">
<legend class="rdk-label">Priorytet</legend>
<div class="flex flex-wrap gap-4">
<label class="inline-flex items-center gap-2">
<input type="radio" class="rdk-radio" name="pattern-priority" checked> Standardowy</label>
<label class="inline-flex items-center gap-2">
<input type="radio" class="rdk-radio" name="pattern-priority"> Pilny</label>
</div>
</fieldset>
<label class="inline-flex items-center gap-2">
<input type="checkbox" class="rdk-checkbox" checked> Zapisz dziennik</label>
<label class="inline-flex items-center gap-2">
<input type="checkbox" class="rdk-toggle" role="switch" checked> Synchronizacja</label>
<div>
<button type="submit" class="rdk-btn rdk-btn-primary h-10 px-4">Zapisz</button>
</div>
<div class="rdk-notice rdk-notice-info p-4" role="status" data-demo-status>Zmiany lokalne czekają na zapis.</div>
</form>
03 / SEMANTYKA

Zasady użycia

Etykiety są jawne; radio tworzą grupę fieldset. Po zapisie aplikacja aktualizuje status. Notice pozostaje w przepływie i nie zasłania kontrolek.
