Dark Horse integration contracts

Control Panel header

Keep it to identity/title, short context, concise current state and optional actions. Keep complex toolbar content out. Application CSS chooses whether narrow headers wrap, stack or move actions below the title and state.

Toggle or remote action

Use Toggle for an immediate, reversible boolean setting such as Auto refresh. Use Button with visible status, and optionally Dialog, for delayed, remote, destructive or confirmation-requiring operations such as restarting a service.

Readout choice

Shared LCD is a single textual/state readout. Dark Horse Instrument Display composes operational value channels. The compact recipe is that same Instrument Display with less metadata and density; application CSS owns its surrounding grid.
