02 / CSS FEATURES

Features used by the library

  • Native <dialog> and its ::backdrop pseudo-element.
  • Browser pseudo-elements for the progress bar.
  • mask-image for vents and mobile documentation navigation.
  • CSS round() in the V1B vent layout.
  • color-mix() for borders, button states and the Navigation Item rail.
  • prefers-reduced-motion to reduce animation.
03 / LIMITATIONS

Before 1.0

Safari, iOS and Android browsers have not been tested. Before 1.0, check fonts, dialog, progress, mask-image and round() on those platforms, repeat screen reader tests and audit the integrating application for accessibility.
