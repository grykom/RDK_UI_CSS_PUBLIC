02 / KONTRAKT

Co nie jest publiczne

Atrybuty data-menu-*, data-dialog-* i data-toast-* sterują wyłącznie skryptem demonstracyjnym. Wewnętrzne zmienne --_rdk-* nie są stabilnym API.
