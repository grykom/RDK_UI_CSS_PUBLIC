Themes / Czarek OS

Czarek OS

Slate-led, content-first bakery workspace with compact editable controls, semantic status colors, and calm density.

Viewport profile: responsive-workspace. Primary: 1440–768 px; secondary: 414 px; wide compatibility: 390 px.

03 / PATTERNS

Theme-specific patterns

These reusable visual patterns are specific to Czarek OS and do not imply cross-theme support. Application CSS owns their layout and application code owns behavior.

Warning status recipe

Czarek OS-only amber/orange treatment on an existing Badge, Notice, or Toast. Use for attention and unsaved review, not deletion or hard failure.

HTML
<span class="rdk-badge cz-status-warning">Needs review</span>

Leading icon and busy button recipe

Czarek OS-only icon sizing and CSS spinner. Application JavaScript sets aria-busy and disabled, then restores both when the action finishes. Supply an accessible name for icon-only buttons.

HTML
<button class="rdk-btn rdk-btn-primary" type="button" aria-busy="false">
<svg class="cz-btn-icon cz-btn-leading" aria-hidden="true">...</svg>
<svg class="cz-btn-icon cz-btn-loader" aria-hidden="true">...</svg>
<span>Save draft</span>
</button>

Enhanced Select

Czarek OS alpha visual primitive for an application-owned combobox/listbox. Use aria-selected for selection and data-active for keyboard highlight. Dirty means unsaved; aria-invalid visually wins over dirty. The application owns keys, focus, value, form synchronization and popup placement.

HTML
<div class="cz-select">
<button type="button" class="cz-select-trigger" role="combobox" aria-haspopup="listbox" aria-expanded="false" aria-controls="mode-options">
<span class="cz-select-value">Automatic (DHCP)</span>
<svg class="cz-select-chevron" aria-hidden="true" viewBox="0 0 24 24">
<path d="m7 10 5 5 5-5"/>
</svg>
</button>
<div id="mode-options" class="cz-select-menu" role="listbox" hidden>
<button type="button" class="cz-select-option" role="option" aria-selected="true">
<span>Automatic (DHCP)</span>
<span class="cz-select-option-check" aria-hidden="true">&#10003;</span>
</button>
</div>
</div>

Measurement Readout

Czarek OS alpha technical value surface with mono tabular numbers and a secondary unit. Use shared Badge or Notice for alarm meaning; this is not an LCD.

HTML
<div class="cz-readout">
<span class="cz-readout-value">4.1234</span>
<span class="cz-readout-unit">V</span>
</div>

Section Icon

Czarek OS alpha decorative icon surface for an ordinary section heading. The application supplies the SVG and heading layout; the icon is not an action.

HTML
<h3>
<span class="cz-section-icon" aria-hidden="true">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor">
<path d="M4 7h16M4 17h16"/>
</svg>
</span> Device settings</h3>
04 / MATURITY

Release status and QA

Status: alpha. Verified in Chrome and Firefox on Windows at 1440, 768, 414, and 390 px; native Showcase and candidate QA. Android Chrome, iOS Safari, and Safari desktop remain untested.

05 / DESIGN

Slate, typography and density

Czarek OS is a compact, content-first workspace theme. White and slate surfaces are the baseline. Emerald marks healthy states. Warning uses a light-amber surface with the author's deliberate dark-red #991b1b text; dirty fields use subtle amber attention. Danger status uses a calm slate surface, while red remains available for destructive action. Do not normalize Czarek OS warning text to amber. The local Source Sans 3 font is bundled with its OFL notice. Compact controls keep usable touch targets on small screens.

06 / CONTROLS

Editable and action states

Editable Input, native Select, Textarea and enabled Button receive restrained elevation. Static Panel and Card remain flat; disabled controls lose elevation. Normal buttons use a lightly tinted slate surface, while Danger is quiet until interaction. Clean, dirty, invalid, focused, disabled and busy states remain distinct. Use data-dirty="true" for subtle amber unsaved attention and aria-invalid="true" for validation: invalid wins when both are present and uses Czarek OS slate, not a bright-red field. Hover and focus remain visible in every enabled state. Add persistent helper/error text via aria-describedby; reduced-motion preferences suppress button motion and busy animation.

07 / RECIPES

Buttons, icons and busy state

A leading 16-18 px Lucide-style SVG can use cz-btn-icon inside rdk-btn. Lucide is recommended, not a runtime dependency. Give an icon-only button an accessible name. For a busy action, keep the label stable, replace the leading icon with cz-btn-loader, set aria-busy="true", and disable repeat activation in application JavaScript. Restore both states after completion.

HTML
<button type="button" class="rdk-btn rdk-btn-primary" aria-busy="false">
<svg class="cz-btn-icon cz-btn-leading" aria-hidden="true">
<use href="#save"/>
</svg>
<svg class="cz-btn-icon cz-btn-loader" aria-hidden="true">
<use href="#loader"/>
</svg>
<span>Save draft</span>
</button>
08 / CHOICES

Native Select and Czarek Patterns

The shared rdk-select stays native; its opened popup belongs to the browser. Enhanced Select is a Czarek OS visual primitive with an official application-owned reference implementation and no required RDK JavaScript. Preserve the documented combobox/listbox ARIA contract if adapting it. Measurement Readout and Section Icon are Czarek-only primitives. The Patterns page documents Field with Unit, Section Header, Status Pill / Status Readout and Diagnostic / Expandable Record. Add cz-number-no-spin to a native number Input only when a plain numeric field without browser stepper controls is intended; spinners remain the default. The helper changes appearance only. Short and long unit suffixes reserve different input space in application CSS. Editable Combobox remains a candidate.
