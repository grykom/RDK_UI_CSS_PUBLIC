Themes / Czarek OS

Czarek OS

Slate-led, content-first bakery workspace with compact editable controls, semantic status colors, and calm density.

Viewport profile: responsive-workspace. Primary: 1440–768 px; secondary: 414 px; wide compatibility: 390 px.

03 / PRIMITIVES

Theme-specific primitives

Primitives belong to one theme. Prompts, logs and timestamps can remain ordinary HTML content.

Warning status recipe

Czarek OS-only amber/orange treatment on an existing Badge, Notice, or Toast. Use for attention and unsaved review, not deletion or hard failure.

HTML
<span class="rdk-badge cz-status-warning">Needs review</span>

Leading icon and busy button recipe

Czarek OS-only icon sizing and CSS spinner. Application JavaScript sets aria-busy and disabled, then restores both when the action finishes. Supply an accessible name for icon-only buttons.

HTML
<button class="rdk-btn rdk-btn-primary" type="button" aria-busy="false">
<svg class="cz-btn-icon cz-btn-leading" aria-hidden="true">...</svg>
<svg class="cz-btn-icon cz-btn-loader" aria-hidden="true">...</svg>
<span>Save draft</span>
</button>
04 / MATURITY

Release status and QA

Status: alpha. Verified in Chrome and Firefox on Windows at 1440, 768, 414, and 390 px; native Showcase and candidate QA. Android Chrome, iOS Safari, and Safari desktop remain untested.

05 / DESIGN

Slate, typography and density

Czarek OS is a content-first workspace theme. Slate grounds the application, white panels carry content, and dark slate navigation gives the page structure. Success uses emerald, attention and dirty values use amber/orange, information uses slate, and destructive or hard failure uses red. The local Source Sans 3 font is bundled with its OFL notice; Helvetica Neue and Arial are fallbacks. Controls stay compact but readable at desktop and mobile widths.

06 / CONTROLS

Editable and action states

Editable Input, native Select, Textarea and enabled Button receive a restrained theme shadow. Static Panel and Card remain flat. Enabled buttons grow subtly on hover without shifting layout; disabled buttons do not. Reduced-motion preferences suppress the motion and spinner animation. An unsaved form value may use data-dirty="true" on a Czarek OS field for amber/orange styling. This is a theme-scoped recipe, not a shared state contract; keep aria-invalid="true" for validation and add visible helper/error text.

07 / RECIPES

Buttons, icons and busy state

A leading 16-18 px Lucide-style SVG can use cz-btn-icon inside rdk-btn. Lucide is recommended, not a runtime dependency. Give an icon-only button an accessible name. For a busy action, keep the label stable, replace the leading icon with cz-btn-loader, set aria-busy="true", and disable repeat activation in application JavaScript. Restore both states after completion.

HTML
<button type="button" class="rdk-btn rdk-btn-primary" aria-busy="false">
<svg class="cz-btn-icon cz-btn-leading" aria-hidden="true">
<use href="#save"/>
</svg>
<svg class="cz-btn-icon cz-btn-loader" aria-hidden="true">
<use href="#loader"/>
</svg>
<span>Save draft</span>
</button>
08 / CHOICES

Select and candidate controls

The shared rdk-select is native: its closed state aligns with other fields, while the opened option popup belongs to the browser. An exact popup match needs an application-owned accessible listbox and JavaScript. Enhanced Select and editable Combobox remain candidate recipes, not stable shared RDK components. Field Group also remains an application composition: join a labelled editable input to a read-only prefix or suffix with one outer border, grouped focus and a unit description. The Native Showcase shows a currency prefix using &euro; and a quantity suffix. The private QA checkpoint exercises the candidate keyboard behavior.

09 / REFERENCE

Native workspace and support

Use the Czarek OS Native Showcase as the canonical visual presentation. Its first part consolidates the approved Stage A visual language with SHARED COMPONENT, THEME RECIPE, COMPOSITION, and CANDIDATE / APPLICATION-OWNED JS labels. Its second part is the compact bakery workspace with responsive navigation, catalog filters, a dense Table, Tabs, status Badges, Notice, Toast, and editable settings. Check the Support Matrix before using a shared component. The tested layout covers 1440, 768, 430 and 390 px in Windows Chrome and Firefox; real mobile devices and Safari remain pending.
