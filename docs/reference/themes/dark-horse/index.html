Themes / Dark Horse

Dark Horse

A dark operational UI theme for control surfaces, monitoring, dashboards and focused utility applications.

Viewport profile: responsive-operational. Primary: 1440–768 px; secondary: 390 px; wide compatibility: 1440 px.

01 / CAPABILITY

03 / PATTERNS

These reusable visual patterns are specific to Dark Horse and do not imply cross-theme support. Application CSS owns their layout and application code owns behavior.

04 / MATURITY

Release status and QA

Status: alpha. Verified in Chromium and Firefox at 390, 768 and 1440 px; public Native Showcase and theme bundle checks. Safari, iOS Safari and Android Chrome real-device QA have not been performed.

05 / SIGNALS

Signal semantics

Dark Horse amber is the accent and active signal, not the warning color. Warning uses a separate orange signal.

RoleMeaning
NeutralStructural / standby / inactive
AccentActive / selected / primary operational emphasis
SuccessNominal / healthy / online
InfoInformational / connected
WarningReview / caution / degraded
DangerError / offline / critical

Segments is supported as the existing RDK segmented progress/readout component. It is not a selectable tabs or segmented-control API. Tooltip is a fallback: its readable appearance is supported, placement stays application-owned, and its content should remain supplementary and non-critical.
