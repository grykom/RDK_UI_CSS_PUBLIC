02 / BASICS

Reusable markup

The markup below is the same markup used by the live preview.

HTML
<div class="relative inline-block" data-menu>
<button type="button" class="rdk-btn h-10 px-4" data-menu-trigger aria-haspopup="menu" aria-expanded="false" aria-controls="doc-menu">Actions ▾</button>
<div id="doc-menu" class="rdk-menu absolute left-0 top-full z-50 mt-2 w-56 p-1" role="menu" aria-label="Profile actions" data-menu-surface hidden>
<div class="rdk-menu-label px-3 py-2">PROFILE</div>
<button type="button" class="rdk-menu-item px-3 py-2" role="menuitem" tabindex="-1">Open</button>
<button type="button" class="rdk-menu-item px-3 py-2" role="menuitem" tabindex="-1" disabled>Eksport</button>
<div class="rdk-menu-separator my-1" role="separator">
</div>
<button type="button" class="rdk-menu-item px-3 py-2" role="menuitem" tabindex="-1" data-tone="danger">Delete</button>
</div>
<p class="text-rdk-text-muted mt-5 text-sm" role="status" data-menu-result>Choose a command.</p>
</div>
03 / WARIANTY I STANY

Available options

Warianty

Default item, disabled item, and danger tone.

Stany

Open or hidden; item hover and focus.

04 / ACCESSIBILITY

Semantics and keyboard

The trigger needs aria-haspopup, aria-controls, and updated aria-expanded. The application handles arrows, Home/End, Escape, and focus return.
05 / TAILWIND + RDK

Composition

RDK classes provide appearance. Tailwind classes in this example control size, padding, grid, spacing, and position. Keep layout utilities in the application.

06 / PUBLIC API

CSS classes

.rdk-menu.rdk-menu-item.rdk-menu-label.rdk-menu-separator
07 / BEHAVIOR

Application responsibility

RDK styles the menu; the application controls opening, selection, keyboard, and focus. data-menu-* attributes belong only to the demo script.
