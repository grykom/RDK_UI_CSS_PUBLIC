Warstwy / Tooltip

Tooltip

Krótka, dodatkowa informacja o kontrolce.

← Wszystkie komponenty
00 / THEMES

Theme support

Console 94 - SUPPORTED

Native pattern. View Native Showcase

Terminal OS - FALLBACK

Usable with native semantics, but not a preferred native composition. Prefer persistent helper text or Notice.

01 / PODGLĄD

Na żywo

Ponawia ustawienie punktu odniesienia.
02 / PODSTAWY

Kod do użycia

Przykład poniżej jest tym samym znacznikiem, którego używa podgląd.

HTML
<span class="relative inline-flex">
<button type="button" class="rdk-btn h-10 px-4" aria-describedby="doc-tip">Kalibracja</button>
<span id="doc-tip" class="rdk-tooltip absolute bottom-full left-0 z-50 mb-2 w-56 p-3 text-xs" role="tooltip">Ponawia ustawienie punktu odniesienia.</span>
</span>
03 / WARIANTY I STANY

Dostępne możliwości

Warianty

Położenie ustala aplikacja, np. Tailwind bottom-full lub right-full.

Stany

CSS pokazuje na hover i focus; ukrywa po ich utracie.

04 / ACCESSIBILITY

Semantyka i klawiatura

Treść jest pomocnicza i bez interaktywnych elementów. Informacje niezbędne muszą być dostępne także bez hover.
05 / TAILWIND + RDK

Kompozycja

Klasy rdk-* nadają wygląd. Klasy Tailwind w przykładzie określają rozmiar, padding, siatkę, odstępy i pozycję. Nie dodawaj odpowiedników układu do publicznego API RDK.

06 / PUBLIC API

Klasy CSS

.rdk-tooltip
07 / ZACHOWANIE

Odpowiedzialność aplikacji

CSS obsługuje prosty hover/focus. Aplikacja zapewnia ewentualne pozycjonowanie z wykrywaniem kolizji.
