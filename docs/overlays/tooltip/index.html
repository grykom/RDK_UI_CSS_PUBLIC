00 / THEMES

Theme support

Czarek OS - FALLBACK

Usable with native semantics, but not a preferred native composition. Prefer persistent helper text next to form controls.

Terminal OS - FALLBACK

Usable with native semantics, but not a preferred native composition. Prefer persistent helper text or Notice.

Dark Horse - FALLBACK

Usable with native semantics, but not a preferred native composition. Fallback styling is readable and visually compatible; position it in application CSS and use it only for supplementary, non-critical information.

CZ / CZAREK OS

Author-aligned appearance

Czarek OS uses a dark slate tooltip. It is a fallback component here: validation errors must also appear as persistent text associated with the field.

03 / WARIANTY I STANY

Available options

Warianty

The application positions it, for example with Tailwind bottom-full or right-full.

Stany

CSS shows it on hover and focus and hides it afterwards.

04 / ACCESSIBILITY

Semantics and keyboard

Keep content supplementary and free of interactive elements. Essential information must also be available without hover.
05 / TAILWIND + RDK

Composition

RDK classes provide appearance. Tailwind classes in this example control size, padding, grid, spacing, and position. Keep layout utilities in the application.
