Playground

Wybierz komponent i kilka wspieranych opcji. Podgląd używa prawdziwych klas RDK, a kod poniżej można wkleić do projektu.

Playground generuje przykładowy, wspierany znacznik. Nie udostępnia wszystkich narzędzi Tailwind ani zachowań aplikacji. Presety rozmiaru są przykładami kompozycji Tailwind, a nie dodatkowym API RDK.
